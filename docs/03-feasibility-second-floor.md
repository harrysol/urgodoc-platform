# 03 — Feasibility: Can a 1955 House Take a Second Floor?

The single biggest unknown isn't design — it's **whether the existing structure
can carry a second story**, or what it costs to make it able to. A 70-year-old
Miami Beach home was not built for a second floor's loads or for current HVHZ
wind code. This is an **engineering** question, answered by a structural engineer
after a site investigation. Below is what they'll be assessing.

## The decision tree

```
Existing foundation + walls strong enough?
├── YES  → Build directly on top (cheapest path)
├── PARTIALLY → Reinforce foundation/walls, then build up (mid cost)
└── NO   → "Pop-top": remove roof, add structural columns/beams or
           a new structural frame to carry the 2nd floor (highest cost)
```

## Key questions the engineer will answer

1. **Foundation** — footings sized for the added dead + live + wind-uplift loads?
   1955 footings usually need verification; sometimes underpinning/widening.
2. **Walls** — CBS (concrete block) walls can often carry more than wood frame,
   but need a continuous, code-compliant **load path** with tie columns/beams.
3. **Lateral / wind** — HVHZ wind uplift on a taller building is severe. New shear
   walls, tie-downs, and a hurricane-rated roof system are typically required.
4. **Existing roof** — removal/rebuild cost; flat/low-slope is generally simpler
   to build up from than complex pitched roofs.
5. **Soil** — Miami Beach is low-lying fill/sand near water; geotech may be needed.

## Common Miami second-floor strategies

- **Full second story over the whole footprint** — maximum space, maximum cost,
  most structural work.
- **Partial second story** — add over part of the footprint (e.g., a primary
  suite). Lighter loads, lower cost, often easier on setbacks.
- **Pop-top with new structural frame** — when existing walls can't carry load,
  a steel/concrete frame takes the new floor independently.

## Cost drivers to keep in mind

- Foundation reinforcement (hidden, expensive, discovered late if you skip the survey).
- HVHZ impact glazing + NOA roofing (required, not optional).
- Flood-elevation compliance possibly forcing ground-floor changes too.
- Temporary relocation during construction (roof comes off).

## Recommended order

1. Get the **survey + structural site investigation** *before* committing to a
   design. Cheap insurance against a six-figure surprise.
2. Use that to decide **partial vs. full** second floor.
3. Only then lock the architectural design and renderings.
